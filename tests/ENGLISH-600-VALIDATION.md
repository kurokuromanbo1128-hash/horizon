## 再実行

通常のGit checkoutで、このmainコミットがローカル履歴にある状態で実行する。

```sh
node tests/english-data.cjs
npm install --no-save playwright@1.62.1
npx playwright install chromium
node tests/regression.cjs
```

`HORIZON_BROWSER`で既存のChrome/Edge実行ファイルを指定可能。`HORIZON_SCREENSHOTS`で画像出力先を指定可能。履歴がないソーススナップショットでは、検証済みmainのファイル一式のディレクトリを`HORIZON_BASE_DIR`に指定できる。今回のローカル実行はmainのGit treeと一致を確認した既存スナップショットを利用した。
